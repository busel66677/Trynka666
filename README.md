# TRYNKA Android 1.1

Готовий офлайн Android-додаток карткової гри «Тринька» на віртуальні фішки.

## Що є
- мобільний преміальний інтерфейс;
- 36 карт, 4 гравці (ви + 3 боти), 3 карти на руку;
- банк, анте, ставки, пас, підтримати, підняти, відкрити;
- таймер ходу;
- спеціальні комбінації: три 6 = 34, три тузи = 33, три 10 = 30;
- збереження фішок і номера раунду на телефоні;
- автоматичний бонус 500 віртуальних фішок, якщо баланс закінчився;
- GitHub Actions автоматично збирає APK.

## APK через GitHub
1. Завантажте весь вміст ZIP у новий GitHub repository.
2. Відкрийте Actions → Build TRYNKA Android → Run workflow.
3. Після завершення відкрийте запуск і завантажте artifact `TRYNKA-debug-APK`.
4. Усередині буде `app-debug.apk`.

Реальні гроші та платежі не використовуються.
